## Data integrity and residual risks

OAuth codes and refresh state remain on the primary database. Principal locks, lifecycle snapshot versions and
tombstones now fence issuance, refresh, framework revocation, session logout and user suspension. PostgreSQL-backed and
full-server HTTP tests cover these races. This is a single-primary guarantee; direct SQL state mutation, mixed old/new
writers or asynchronous multi-region replication are outside it. Role creation/permission mutation and client management
do not yet have complete audit, idempotency or concurrent-update contracts. Selected audit rows do not establish tamper
resistance. Recovery, federation and multi-region behaviors are design guidance only where marked unimplemented.
Self-contained JWTs remain valid independent of directory changes unless a PEP requests a fresh decision.
